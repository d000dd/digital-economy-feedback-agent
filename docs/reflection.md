# 反思总结

本次项目选择“数字经济课程反馈分析”作为真实场景，是因为课程反馈既有文本理解需求，也有办公协同需求，适合体现智能体应用的完整流程。

## 收获

1. 明确了智能体边界。系统只负责辅助整理和建议，不替代教师判断。
2. 形成了可运行工作流。输入、分析、输出、飞书推送和测试形成闭环。
3. 体会到工具的重要性。CLI、Web UI、文件导出和飞书机器人让模型结果变成可执行流程。
4. 通过测试提高可靠性。规则分类和飞书签名都有单元测试，演示时更稳定。

## 不足

1. 当前默认规则引擎适合课程反馈场景，泛化能力有限。
2. 飞书集成使用自定义机器人 Webhook，还没有直接写入飞书表格。
3. 关键词提取没有使用中文分词库，复杂长文本的关键词可能不够精确。

## 后续改进

1. 接入飞书表格 API，把每条反馈和处理状态写入多维表格。
2. 增加人工确认环节，让教师修改分类后反向优化规则。
3. 接入大模型做更细致的原因归纳和报告润色。
4. 增加可视化趋势图，比较不同周次、班级和主题的变化。
