# 项目设计说明

## 场景与边界

本项目解决数字经济课程反馈的收集、分析和协同问题。智能体不替代教师决策，只负责把原始反馈转化为可检查的结构化信息，包括主题、情绪、优先级、关键词和建议动作。

不处理的边界：

- 不保存飞书 Webhook 密钥；
- 不对学生个人做画像；
- 不给出成绩或学术评价结论；
- 无法确认输入真实性时，只输出“建议人工复核”。

## 智能体工作流

1. 输入采集：读取 CSV、TXT 或手动粘贴文本。
2. 数据清洗：移除空白记录，保留来源、班级和时间字段。
3. 主题分类：基于数字经济课程场景关键词映射到 8 类主题。
4. 情绪识别：通过正向词和负向词判断“正向 / 中性 / 负向”。
5. 优先级判断：将考试、截止、系统不可用等高风险反馈标为高优先级。
6. 关键词提取：抽取命中词和短文本关键词。
7. 建议生成：按主题匹配行动模板，形成教师/助教可执行建议。
8. AI 增强：若配置 `OPENAI_API_KEY`，使用真实 AI 润色摘要；失败时回退到规则结果。
9. 协同输出：生成 Markdown 报告、CSV 明细、飞书机器人卡片。

## 核心模块

| 文件 | 职责 |
| --- | --- |
| `agent.py` | 编排完整分析流程 |
| `data_loader.py` | 读取 CSV、JSON、JSONL、TXT 输入 |
| `nlp.py` | 规则分类、情绪、优先级、关键词 |
| `llm.py` | 使用 `OPENAI_BASE_URL` 和 `OPENAI_API_KEY` 接入真实 AI |
| `feishu.py` | 飞书机器人签名、卡片构造、重试发送 |
| `cli.py` | 项目运行、分析、样例生成 |
| `server.py` | Web UI 本地 API |

## 模型任务与工具任务

模型任务：

- 理解反馈意图；
- 总结主要问题；
- 生成行动建议；
- 使用真实 AI 润色摘要，或在未配置/失败时使用离线规则。

工具任务：

- CLI 执行分析、生成样例、启动跨设备 Web 服务；
- Python 脚本读取文件和导出报告；
- Web UI 完成交互；
- 飞书机器人推送协同消息；
- 单元测试验证稳定性。

## 异常处理

| 异常 | 处理方式 |
| --- | --- |
| 空输入 | 返回空结果和补充输入建议 |
| CSV 字段名不统一 | 自动识别 `text/feedback/content/意见/反馈/评价/建议` |
| 分类不确定 | 归为“其他”，并标注人工复核 |
| 飞书未配置 | 分析照常完成，只返回缺少 URL 的错误信息 |
| 飞书网络失败 | 最多重试 3 次，返回失败原因 |
| AI 不可用 | 自动回退到离线规则引擎，并在结果中记录 warning |
