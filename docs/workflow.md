# 工作流说明

```mermaid
flowchart TD
    A[用户输入文本或 CSV] --> B[数据读取与清洗]
    B --> C{是否有有效反馈}
    C -- 否 --> D[返回空结果与补充提示]
    C -- 是 --> E[主题分类]
    E --> F[情绪识别]
    F --> G[优先级判断]
    G --> H[关键词提取]
    H --> I{是否配置真实 AI}
    I -- 是 --> I1[AI 润色摘要]
    I -- 否/失败 --> I2[规则摘要]
    I1 --> J[生成 Markdown 报告]
    I2 --> J[生成 Markdown 报告]
    J --> K[生成 CSV 明细]
    J --> L{是否配置飞书}
    L -- 是 --> M[签名并推送飞书卡片]
    L -- 否 --> N[保留本地结果]
```

## 智能体逻辑结构

本项目采用“感知-分析-行动”的轻量智能体结构。

感知层：

- 从 CSV、TXT、Web 文本框接收输入；
- 自动识别中文字段；
- 过滤空白和无效内容。

分析层：

- 主题分类；
- 情绪识别；
- 优先级判断；
- 关键词提取；
- 真实 AI 摘要润色，失败时回退到规则摘要。

行动层：

- 生成 Markdown 报告；
- 生成可下载 CSV；
- 通过飞书机器人推送给班级或课程团队；
- 通过 CLI、Docker 和环境变量支持跨设备部署。
