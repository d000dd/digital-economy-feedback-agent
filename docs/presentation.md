# 展示材料

## 第 1 页：项目题目

数字经济课程反馈分析与飞书通知智能体

核心目标：把分散的课程反馈转化为可执行的教学改进建议，并同步到飞书协同流程。

## 第 2 页：真实场景问题

- 学生反馈来源分散；
- 人工整理耗时；
- 高优先级问题容易被聊天记录淹没；
- 教师和助教缺少统一的复盘材料。

## 第 3 页：系统输入与输出

输入：

- CSV 表格；
- 多行文本；
- Web 页面手动粘贴。

输出：

- 主题分类明细；
- 情绪与优先级；
- Markdown 报告；
- 飞书机器人卡片。

## 第 4 页：智能体工作流

读取数据 -> 清洗 -> 分类 -> 情绪识别 -> 优先级判断 -> 关键词提取 -> 建议生成 -> 报告与飞书推送。

## 第 5 页：模型与工具分工

模型任务：

- 理解反馈含义；
- 总结问题；
- 生成行动建议。

工具任务：

- CLI 运行；
- Web UI 交互；
- 文件导出；
- 飞书 Webhook；
- 单元测试。

## 第 6 页：演示步骤

1. 启动 Web 服务；
2. 粘贴或上传课程反馈；
3. 点击分析；
4. 查看主题分布、明细表和建议动作；
5. 查看右上角 Live AI / Rules fallback 状态；
6. 导出报告；
7. 推送到飞书群。

## 第 7 页：测试与迭代

- 使用 `unittest` 覆盖数据读取、分类、报告和飞书签名；
- 对空输入、缺少飞书配置、分类不确定等异常进行处理；
- 未配置 API key 时离线运行；配置 `OPENAI_API_KEY` 后自动接入真实 AI。

## 第 8 页：反思总结

本项目体现了智能体在真实学习场景中的价值：不是简单聊天，而是把输入、模型理解、工具执行和协同通知串成完整流程。后续可接入飞书表格 API，把分析结果自动写入课程反馈台账。
